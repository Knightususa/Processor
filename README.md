# Проект: Ассемблер и Процессор (стековая виртуальная машина)

## Описание проекта

Данный проект представляет собой реализацию **ассемблера** и **процессора** для стековой виртуальной машины. Он позволяет писать программы на простом ассемблере, транслировать их в бинарный байт-код и исполнять на виртуальном процессоре. Также реализована поддержка графики через библиотеку **raylib** (видеопамять 100×100 пикселей, команды `draw`, `initw`, `closew`).

Проект состоит из трёх основных частей:

- **Ассемблер** — читает текстовый файл с программой, парсит команды и метки, записывает байт-код в бинарный файл.
- **Процессор** — читает бинарный байт-код и исполняет команды.
- **Stack_lib** — библиотека для работы со стеком, используемая процессором.

## Команды процессора

| Команда | Аргументы | Описание |
|---------|-----------|----------|
| `hlt` | — | Остановка процессора |
| `push <arg>` | 1 | Положить значение в стек. Поддерживает регистры (`ax`…`jx`), числа, память `[arg]`, `{arg}` (VRAM) Также поддерживает ввод буквы(push a) как значение ASCII кода буквы, для последующего вывода outc|
| `pop <arg>` | 1 | Снять значение со стека и записать в регистр/память |
| `out` | — | Вывести верхний элемент стека (число) |
| `outc` | — | Вывести верхний элемент стека как символ |
| `add` | — | Сложить два верхних элемента стека |
| `sub` | — | Вычесть (второй − верхний) |
| `mul` | — | Умножить два верхних элемента |
| `div` | — | Разделить (второй ÷ верхний) |
| `sqrt` | — | Квадратный корень верхнего элемента |
| `in` | — | Ввести число с клавиатуры и положить в стек |
| `jmp <label>` | 1 | Безусловный переход на метку |
| `je <label>` | 1 | Переход, если равны |
| `jne <label>` | 1 | Переход, если не равны |
| `ja <label>` | 1 | Переход, если больше |
| `jae <label>` | 1 | Переход, если больше или равно |
| `jb <label>` | 1 | Переход, если меньше |
| `jbe <label>` | 1 | Переход, если меньше или равно |
| `call <label>` | 1 | Вызов подпрограммы (сохраняет адрес возврата) |
| `ret` | — | Возврат из подпрограммы |
| `rand <n>` | 1 | Сгенерировать случайное число [0,n) |
| `initw` | — | Инициализировать окно (raylib) |
| `closew` | — | Закрыть окно |
| `draw` | — | Отрисовать VRAM на экране |

### Регистры

Доступно 10 регистров: `ax`, `bx`, `cx`, `dx`, `ex`, `fx`, `gx`, `hx`, `ix`, `jx`.

### Адресация

- `push 5` — положить число 5
- `push ax` — положить значение регистра `ax`
- `push [5]` — положить значение из RAM по адресу 5
- `push [ax + 5]` — положить значение из RAM по адресу `ax + 5`
- `push {5}` — положить значение из VRAM по адресу 5 (смещение добавляется автоматически)
- `push {ax}` — положить значение из VRAM по адресу `ax`

### Метки

Метки задаются строкой, начинающейся с `:`:

```asm
:loop
    push 1
    out
    jmp :loop
```
### Компиляция и запуск
#### Требования
Компилятор C++ (g++ / clang++)

Библиотека raylib (для графических команд) — путь к заголовкам указан в draw_func.h

Stack_lib — должна быть собрана и доступна для линковки

### Ассемблер
#### Компиляция:

```bash
g++ Source/assembler.cpp Source/common.cpp -I Headers -I Stack_lib/Headers -o assembler.exe
```
#### Запуск:

```bash
./assembler.exe -i program.txt
```
Ассемблер читает Code_txt/program.txt, транслирует в байт-код и сохраняет в Code_bin/program.bin.

### Процессор
#### Компиляция:

```bash
g++ Source/processor_main.cpp Source/processor_func.cpp Source/common.cpp Source/draw_func.cpp \
    -I Headers -I Stack_lib/Headers -lraylib -lm -o processor.exe
```
#### Запуск:

```bash
./processor.exe -i Code_bin/program.bin
```
Процессор читает байт-код и исполняет его. Если программа использует графические команды (initw, draw, closew), откроется окно raylib.

### Пример программы
Code_txt/Fucktorial.txt:

```asm
in
pop ax
push 1
pop bx
call :facktorial
out
hlt

:facktorial
    push ax
    push 1
    jbe :base
        push ax
        push bx
        mul
        pop bx
        push ax
        push 1
        sub
        pop ax
        call :facktorial
        ret

    :base
        push bx
        ret
```
Программа по введенному числу вычисляет его факториал

### Отладка
Для включения отладочного вывода процессора определите макрос PROC_DEBUG при компиляции:

```bash
g++ ... -DPROC_DEBUG ...
```
Для включения проверок (yaissert) определите ON_DEBUG:

```bash
g++ ... -DON_DEBUG ...
```
### Примечания
Байт-код хранится в бинарном виде, команды кодируются с битовыми полями (см. View и BitField в global.h).

VRAM расположена в конце RAM (смещение delta_size_RAM)
